# Esercizio 479 - Calcolatrice SOAP

Questa applicazione Python/Flask utilizza il servizio web SOAP della calcolatrice disponibile su:

- http://www.dneonline.com/calculator.asmx

## Funzionalità

- Add
- Subtract
- Multiply
- Divide

## Esecuzione

1. Apri un terminale in `esercizi\\479`
2. Installa Flask se non già presente:
   ```
   python -m pip install flask
   ```
3. Installa le dipendenze:
   ```
   python -m pip install flask zeep
   ```
4. Avvia l'app:
   ```
   python app479.py
   ```
5. Apri nel browser:
   `http://127.0.0.1:5000`
